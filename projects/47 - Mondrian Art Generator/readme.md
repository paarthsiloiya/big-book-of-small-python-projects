# Mondrian Art Generator - Digital Canvas 🎨

An enhanced digital art generator that creates infinite abstract compositions inspired by Piet Mondrian's iconic geometric style with modern interactive features.

## Enhanced Features

### 🌈 **Multiple Art Modes**
- **Complexity Levels**: Simple, Medium, Complex grid variations
- **Color Palettes**: Classic Mondrian, Extended colors, Monochrome options
- **Auto-Generation**: Continuous art creation with timed intervals
- **Interactive Controls**: Manual step-through or automated display

### 🎯 **Smart Art Generation**
- **Dynamic Grid System**: Adaptive line placement based on complexity
- **Intelligent Segmentation**: Advanced line removal algorithms
- **Flood Fill Coloring**: Precise rectangle identification and painting
- **Balanced Compositions**: Calculated rectangle-to-line ratios

### 💾 **Export & Customization**
- **Art Saving**: Export compositions to text files with metadata
- **Cross-Platform**: Works with or without bext library dependency
- **ANSI Fallback**: Color support even without external libraries
- **Terminal Adaptation**: Automatic size detection and adjustment

## How to Use

### Basic Operation
1. **Run**: `python main.py`
2. **Configure**: Choose complexity (1-3) and color palette (1-3)
3. **Generate**: Press Enter for new art or enable auto mode
4. **Save**: Use 'S' command to export your favorite pieces

### Advanced Controls
- **[Enter]**: Generate new artwork manually
- **[S]**: Save current artwork to file
- **[A]**: Switch to automatic generation mode  
- **[Q]**: Quit the program
- **[Ctrl+C]**: Stop auto mode or exit

### Configuration Options
- **Complexity 1**: Simple grids with larger rectangles
- **Complexity 2**: Medium density (classic Mondrian style)
- **Complexity 3**: Complex grids with intricate patterns
- **Classic Palette**: Traditional red, yellow, blue, black, white
- **Extended Palette**: Additional green, magenta, cyan colors
- **Monochrome**: Black and white minimalist compositions

## Technical Features

- **Dual Library Support**: Optimized for bext library with ANSI fallback
- **Geometric Algorithms**: Mathematical line intersection and removal logic
- **Memory Efficient**: Canvas dictionary system for large terminal displays
- **Cross-Platform**: Windows and Unix terminal compatibility

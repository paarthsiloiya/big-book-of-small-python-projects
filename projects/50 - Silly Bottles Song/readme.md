# Silly Bottles Song - Progressive Chaos 🍼

An enhanced version of the classic "99 Bottles" song that progressively corrupts the lyrics with random effects, creating an increasingly silly and chaotic experience.

## Enhanced Features

### 🎮 **Customization Options**
- **Custom starting bottles**: Choose any number from 1-999
- **Speed modes**: Slow, Medium, Fast typing speeds
- **Chaos levels**: Mild, Medium, Wild corruption intensity
- **Interactive configuration**: Easy setup with helpful defaults

### 🎭 **Progressive Corruption System**
- **Random text effects**: Character replacement, case swapping, transposition
- **L33t speak conversion**: Letters become numbers and symbols (@, 3, !, 0, $, 7)
- **Character insertion/deletion**: Words gradually become unrecognizable
- **Escalating chaos**: Effects compound over time for maximum silliness

### 🌈 **Visual Enhancements**
- **Color-coded verses**: Every 10th verse gets special coloring
- **Progress tracking**: Visual progress bar every 10 verses
- **Welcome screen**: Beautiful ASCII art introduction
- **Real-time statistics**: Character corruption tracking

### 💾 **Export Features**
- **Auto-save snapshots**: Saves corrupted lyrics every 25 verses
- **Final lyrics export**: Save the completely corrupted version
- **Corruption statistics**: Detailed analysis of text degradation
- **Timestamped files**: Each save includes verse number

### 🚀 **Interactive Controls**
- **Graceful interruption**: Ctrl+C shows statistics before exit
- **Progress display**: Shows completion percentage and verse count
- **Cross-platform**: Works on Windows, Mac, and Linux
- **Smart formatting**: Handles singular/plural bottle grammar

## How to Use

1. **Run**: `python main.py`
2. **Configure**: Set bottles, speed, and chaos level
3. **Watch**: Enjoy the progressive text corruption
4. **Interrupt**: Press Ctrl+C anytime to see final statistics

### Configuration Options
- **Bottles**: 1-999 (default: 99)
- **Speed**: 1=Slow, 2=Medium, 3=Fast (default: Medium)
- **Chaos**: 1=Mild, 2=Medium, 3=Wild (default: Medium)

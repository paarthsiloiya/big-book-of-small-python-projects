# Multiplication Table Generator 📊

An enhanced interactive multiplication table generator with customizable ranges, colors, analysis features, and export capabilities.

## Enhanced Features

### 🔢 **Customizable Tables**
- **Custom ranges**: Choose any start and end numbers (up to 50 numbers wide)
- **Specific multiplication tables**: Focus on individual number tables (e.g., 7× table)
- **Full grid display**: Traditional multiplication table format
- **Smart formatting**: Automatic column alignment and spacing

### 🎨 **Visual Enhancements**
- **Color-coded output**: Different colors for zeros, even/odd numbers
- **Perfect square highlighting**: Special marking with ² symbol and yellow color
- **Interactive color toggle**: Enable/disable colors during runtime
- **Clean table borders**: Professional grid layout with separators

### 📊 **Analysis Features**
- **Table statistics**: Total calculations, perfect square count and ratios
- **Mathematical insights**: Pattern recognition in multiplication results
- **Color legend**: Clear explanation of color coding system
- **Range validation**: Prevents overly large tables that would be unwieldy

### 💾 **Export Capabilities**
- **File saving**: Export tables to .txt files with proper formatting
- **Custom filenames**: Automatic naming based on range or specific number
- **Formatted output**: Maintains table structure in saved files
- **Perfect square preservation**: Saves ² notation for perfect squares

### 🎯 **Interactive Controls**
- **Runtime options**: New table, save, color toggle, quit commands
- **Input validation**: Handles invalid inputs gracefully
- **Cross-platform**: Works on Windows, Mac, and Linux systems
- **Screen clearing**: Clean interface transitions between operations

## Color System

- **Gray**: Zero values
- **Yellow**: Perfect squares (1, 4, 9, 16, 25, etc.) marked with ²
- **Blue**: Even numbers
- **Green**: Odd numbers

Perfect for mathematics education, pattern recognition, and anyone needing custom multiplication reference tables!

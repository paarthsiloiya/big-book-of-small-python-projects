# Progress Bar

A simple and reusable progress bar animation for your Python scripts.

## How It Works

This program simulates a file download task to demonstrate a text-based progress bar. It updates in real-time on the same line in the terminal.

## Features

-   **Visual Indicator**: Uses block characters to show progress.
-   **Percentage**: Displays the current completion percentage.
-   **Counters**: Shows current vs. total amount.
-   **Customizable**: Easy to adjust width and characters.

## Usage

Run the script to see the simulation:
`python main.py`

You can copy the `get_progress_bar` function into your own projects to add a progress indicator to long-running tasks.

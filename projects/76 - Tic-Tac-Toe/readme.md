# Tic-Tac-Toe

A classic strategy game for two players, X and O, who take turns marking the spaces in a 3x3 grid.

## How to Play

1.  The game is played on a grid that's 3 squares by 3 squares.
2.  You are **X**, your friend (or the computer in this case playing as the second player) is **O**. 
3.  Players take turns putting their marks in empty squares.
4.  The first player to get 3 of her marks in a row (up, down, across, or diagonally) is the winner.
5.  When all 9 squares are full and no player has 3 marks in a row, the game ends in a tie.

## Running the Game

Run the script using Python:
```bash
python main.py
```

Choose a position from 1-9 corresponding to the board layout:

 1 | 2 | 3 
---+---+---
 4 | 5 | 6 
---+---+---
 7 | 8 | 9 

Have fun!

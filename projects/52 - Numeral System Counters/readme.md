# Numeral System Counters

Enhanced number base converter that displays numbers in multiple numeral systems with customizable features and export capabilities.

## Enhanced Features

### 🔢 **Multiple Number Systems**
- **Decimal (base 10)**: Standard counting system
- **Binary (base 2)**: Computer-friendly 0s and 1s
- **Octal (base 8)**: Traditional computer system
- **Hexadecimal (base 16)**: Memory addresses and colors
- **Custom bases**: Any base from 2 to 36 (uses A-Z for digits 10-35)
- **Roman numerals**: Classical I, V, X, L, C, D, M system (1-3999)

### ⚙️ **Customization Options**
- **Custom starting number**: Begin counting from any non-negative integer
- **Flexible count**: Display any number of consecutive values
- **Multiple bases**: Show combinations of different bases simultaneously
- **Digit separators**: Group long binary/hex numbers for readability
- **Animated display**: Optional delays between numbers for demonstrations

### 💾 **Export & Control Features**
- **File export**: Save results to formatted text files
- **Progress control**: Pause every 50 numbers with continue/save options
- **Graceful interruption**: Ctrl+C offers to save current progress
- **Batch processing**: Handle large ranges efficiently

### 📊 **Display Formatting**
- **Aligned columns**: Clean, professional table layout
- **Smart spacing**: Automatic column width adjustment
- **Readable separators**: Space-separated groups in long numbers
- **Multiple format support**: Accommodates various base lengths

## Usage Examples

### Basic Usage
```
Starting number: 0
Count: 100
Bases: 2,8,16
Result: DEC/BIN/OCT/HEX table for 0-99
```

### Advanced Configuration
```
Starting number: 1000
Count: 50
Bases: 2,3,16
Roman numerals: Yes
Separators: Yes
Result: Multi-base table with Roman numerals
```

### Custom Base Systems
```
Bases: 3,7,12,20
Shows numbers in unusual bases for mathematical exploration
```

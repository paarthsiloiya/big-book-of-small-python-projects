# Three Card Monte

Can you follow the Queen of Hearts? This is a classic scam, now in Python form!
Keep your eyes peeled as the cards are shuffled around.

## How to Play

1.  The game starts with three cards: two random cards and the **Queen of Hearts**.
2.  Memorize the starting position of the Queen.
3.  The cards will be rapidly swapped. Watch carefully!
4.  After the shuffling stops, guess which position holds the Queen: **LEFT**, **MIDDLE**, or **RIGHT**.

## The Switch

In real life, the dealer often uses sleight of hand to trick you.
Here, the Python script performs the swaps right before your eyes.
The challenge is to keep track of the Queen's location through multiple swaps.

## Running the Game

Run the script using Python:
```bash
python main.py
```

Good luck, and don't blink!

# Gullible - The Ultimate Prank Program

Welcome to **Gullible**, a clever little prank that demonstrates the power of infinite loops in programming! This deceptively simple program will keep someone occupied indefinitely with a single, seemingly innocent question.

## How It Works

The program asks: *"Do you want to know how to keep a gullible person busy for hours? (yes/no)"*

- **Answer "yes"**: The question repeats immediately, creating an endless loop
- **Answer "no"**: The program finally ends (but who would say no to learning something?)
- **Invalid answer**: You're politely asked to enter 'yes' or 'no'

## The Psychology

This prank works because:
- **Curiosity**: People naturally want to know the "secret" 
- **Persistence**: After a few loops, they're determined to see what happens
- **Realization**: Eventually they understand *they are* the gullible person being kept busy

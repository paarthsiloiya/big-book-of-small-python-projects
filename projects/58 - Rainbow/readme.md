# Rainbow

A simple colorful animation that moves back and forth across the terminal screen.

## Requirements

This program requires the `bext` module for colored output.
`pip install bext`

## How It Works

The program prints a sequence of colored blocks that shift indentation over time, creating a zigzagging rainbow effect.

## Usage

Run the script to start the animation:
`python main.py`

Press `Ctrl-C` to stop the animation.

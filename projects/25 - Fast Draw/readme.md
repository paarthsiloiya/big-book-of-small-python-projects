# Fast Draw - Reaction Time Challenge Game

Test your lightning-fast reflexes with this **Wild West-style reaction game**! Challenge yourself to draw as quickly as possible when you see "DRAW!" appear on screen. How fast can your fingers move when the stakes are high? This thrilling game measures your reaction time with millisecond precision.

## What This Program Does

This adrenaline-pumping reaction game puts your reflexes to the ultimate test:

- **Random Timing**: Unpredictable wait periods from 1-4 seconds keep you on edge
- **Millisecond Precision**: Uses high-resolution timing for accurate measurements
- **Anti-Cheat System**: Detects premature key presses and suspiciously fast times
- **Performance Feedback**: Real-time evaluation of your reaction speed
- **Continuous Play**: Keep playing to improve your personal best time
- **Clean Interface**: Simple, distraction-free terminal-based gameplay

## Game Mechanics

### The Challenge

Wait for the magic moment when "DRAW!" appears, then press Enter as fast as humanly possible:

```
Get ready to draw! Press Enter as soon as you see 'DRAW!'
Press Enter to start...

[Random delay of 1.0 to 4.0 seconds]

DRAW!  ← Press Enter NOW!
```

# Leetspeak - Advanced Text Transformation Tool

Welcome to **Leetspeak**, a comprehensive text transformation utility that converts regular English into the iconic internet slang known as "l33tsp34k" or "1337 speak"! This enhanced version goes far beyond simple character replacement, offering multiple modes, intensity levels, and advanced features for all your text transformation needs.

## How It Works

### Character Substitution System
The program uses an extensive mapping of 200+ character combinations:
- **Traditional replacements**: 'a' → '4', 'e' → '3', 's' → '$'
- **Advanced symbols**: Unicode characters like 'λ', '€', '§'
- **Multi-character patterns**: 'ph' for 'f', '/\\/' for 'n'
- **Context-aware selection**: Random choice from multiple options per letter

## Feature-Rich Modes

### 1. Single Text Conversion
- **Interactive input**: Enter any message for instant conversion
- **Intensity control**: Choose from 4 different transformation levels
- **Case preservation**: Option to maintain original capitalization
- **Instant clipboard**: Automatic copying of results (when available)

### 2. Batch File Processing  
- **Mass conversion**: Transform entire text files at once
- **Organized output**: Clean formatting with original and converted text
- **Error handling**: Graceful management of file operations
- **Custom naming**: Choose your own output filenames

### 3. Interactive Live Mode
- **Real-time conversion**: Type and see instant l33tsp34k transformation
- **Continuous session**: Keep converting without restarting
- **Quick exit**: Simple 'quit' command to return to menu

### 4. Reverse Decoder
- **L33t to English**: Convert leetspeak back to readable text
- **Pattern recognition**: Intelligent matching of complex character combinations
- **Multi-length parsing**: Handles both single and multi-character substitutions

## Intensity Levels

Choose your preferred transformation strength:
- **MILD (30%)**: Subtle changes maintaining readability
- **MEDIUM (50%)**: Balanced transformation for everyday use
- **HEAVY (70%)**: Classic leetspeak experience with significant alteration  
- **EXTREME (90%)**: Maximum transformation for hardcore l33t effect

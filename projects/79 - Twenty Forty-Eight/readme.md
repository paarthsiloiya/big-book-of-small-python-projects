# 2048

The classic sliding tile puzzle game. Join the numbers and get to the **2048** tile!

## How to Play

1.  **Grid**: The game is played on a 4x4 grid.
2.  **Move**: Use **WASD** keys to slide tiles.
    *   **W**: Up
    *   **A**: Left
    *   **S**: Down
    *   **D**: Right
3.  **Combine**: When two tiles with the same number touch, they merge into one!
    *   2 + 2 = 4
    *   4 + 4 = 8
    *   ...and so on.
4.  **Goal**: Create a tile with the number **2048**.
5.  **Game Over**: The game ends when the board is full and no more moves are possible.

## Running the Game

Run the script using Python:
```bash
python main.py
```

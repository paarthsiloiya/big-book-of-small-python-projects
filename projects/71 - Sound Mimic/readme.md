# Sound Mimic

A memory game inspired by Simon. Memorize the growing pattern of sounds and letters.

## How to Play

1.  The game will display and play a sequence of letters (A, S, D, F).
2.  Memorize the sequence.
3.  The screen will clear.
4.  Type the sequence back and press Enter.
5.  If you are correct, the sequence gets longer.
6.  If you are wrong, the game ends.

## Controls

-   `A`, `S`, `D`, `F`: The keys used in the pattern.
-   `Enter`: Submit your answer.

## Features

-   **Built-in Audio**: Uses Windows system beeps, so no external sound files are required.
-   **Progressive Difficulty**: The pattern grows by one character each round.

## Requirements

-   Windows (for audio support via `winsound`).
-   Python 3.x

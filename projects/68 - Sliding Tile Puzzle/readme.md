# Sliding Tile Puzzle

A classic sliding tile puzzle game where you rearrange tiles to put them in order.

## How to Play

1.  The game starts with a 4x4 grid of numbered tiles (1-15) and one blank space.
2.  The tiles are scrambled.
3.  Use the **WASD** keys to slide tiles into the blank space.
    -   **W**: Slide tile up (blank moves down)
    -   **A**: Slide tile left (blank moves right)
    -   **S**: Slide tile down (blank moves up)
    -   **D**: Slide tile right (blank moves left)
4.  The goal is to arrange the tiles in numerical order from 1 to 15, with the blank space in the bottom-right corner.

## Controls

-   `W`, `A`, `S`, `D`: Move tiles.
-   `QUIT`: Exit the game.

# Rock Paper Scissors (Always Win)

A humorous variation of the classic game where the player always wins.

## How to Play

1.  Run the program.
2.  Enter `R` for Rock, `P` for Paper, or `S` for Scissors.
3.  The computer will always choose the losing move against you.
4.  Enjoy your endless winning streak!

## Controls

-   `R`, `P`, `S`: Choose your move.
-   `Q`: Quit the game.

## Usage

Run the script to start the game:
`python main.py`

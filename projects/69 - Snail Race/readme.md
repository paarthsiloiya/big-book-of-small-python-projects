# Snail Race

A fast-paced snail racing simulation game.

## How to Play

1.  Run the program.
2.  Enter the number of snails you want to race (2-8).
3.  Give each snail a unique name.
4.  Watch the race unfold! The snails move forward randomly.
5.  The first snail to reach the finish line wins.

## Features

-   **Dynamic Animation**: The race is animated in the terminal.
-   **Custom Names**: You can name your snails.
-   **Randomized Movement**: Every race is different.

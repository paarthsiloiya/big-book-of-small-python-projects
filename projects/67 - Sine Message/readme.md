# Sine Message

A simple animation program that displays a custom message moving in a sine wave pattern with rainbow colors.

## How to Run

1. Run the script using Python.
2. Enter the message you want to display when prompted.
3. Watch your message wave across the screen!

## Controls

- **Ctrl-C**: Stop the animation and exit the program.

## Features

- Smooth sine wave animation
- Cycling rainbow colors
- Auto-adjusts to terminal width

Enjoy the mesmerizing wave!

# Trick Questions

A quiz game that challenges you with riddles and trick questions. Think outside the box!

## How to Play

1.  Run the game. A random question will appear.
2.  Type your answer into the prompt.
3.  These are "trick" questions, so the obvious answer is often wrong!
4.  If your answer contains a keyword that matches the solution, you get a point.
5.  Type `quit` at any time to exit the game.

## Running the Game

Run the script using Python:
```bash
python main.py
```

## Example

**Question**: What do you have to do to survive being bitten by a poisonous snake?
**Answer**: Nothing. (Only *venomous* snakes are deadly; poisonous snakes are only harmful if you eat them!)

Can you get them all right?

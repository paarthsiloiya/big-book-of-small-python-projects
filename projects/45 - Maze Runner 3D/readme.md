# Maze Runner 3D - First Person Maze Adventure 🏛️

An enhanced 3D first-person maze navigation game with immersive graphics and multiple maze options.

## What's New in This Version

### 🌟 Enhanced Features
- **Beautiful 3D visualization** with enhanced border graphics and emojis
- **Random maze generation** alongside traditional file loading
- **Step counter** to track your progress and challenge yourself
- **Enhanced help system** with detailed command explanations
- **Cross-platform screen clearing** for smooth visual experience
- **Improved status display** showing position, direction, and maze type

### 🎮 Gameplay Options
- **Load Custom Mazes**: Use existing maze files with complex layouts
- **Random Mazes**: Generate simple procedural mazes for quick games
- **Teleport Cheat**: Use T x,y command for debugging or exploration

## How to Play

1. **Start**: Run `python main.py`
2. **Choose Maze Type**: Select file loading or random generation  
3. **Navigate**: Use first-person view to explore the maze
4. **Find Exit**: Look for the EXIT sign and reach it to win!

### 🕹️ Controls
- **F or W**: Move forward in current direction
- **L or A**: Turn left (counterclockwise)
- **R or D**: Turn right (clockwise)  
- **H**: Show detailed help menu
- **Q**: Quit game anytime
- **T x,y**: Teleport to coordinates (cheat code)

## 3D Perspective System

The game renders a **first-person 3D view** showing:
- **Walls and passages** in realistic perspective
- **Distance effects** with different wall sections (A-F zones)
- **Exit signs** when the exit is visible in your view
- **Atmospheric lighting** with torch-like border effects

# Prime Number Explorer

An advanced prime number calculator and explorer with multiple discovery modes, optimized algorithms, and comprehensive analysis features for mathematical exploration and education.

## Features

- **Multiple Discovery Modes**:
  - Single number primality testing with timing analysis
  - Range-based prime finding with Sieve of Eratosthenes optimization
  - Continuous prime search with real-time statistics
  - Prime factorization for composite numbers
- **Optimized Algorithms**:
  - Enhanced trial division (skips even numbers)
  - Sieve of Eratosthenes for efficient range calculations
  - Performance timing and rate calculations
- **Advanced Analysis**:
  - Prime factors display for composite numbers
  - Search statistics (count, rate, elapsed time)
  - Large number formatting with comma separators
  - Progress tracking for long calculations

## Usage Modes

### Single Number Check
Test individual numbers for primality with detailed analysis including calculation time and prime factorization for composite numbers.

### Range Search  
Find all primes within a specified range using optimized algorithms. Automatically uses Sieve of Eratosthenes for ranges up to 1 million.

### Continuous Search
Real-time prime discovery starting from any number with live statistics display including discovery rate and elapsed time.

### Educational Features
Built-in prime number facts and mathematical properties for learning about prime theory and applications.

## Performance Optimizations

- **Smart Algorithm Selection**: Chooses optimal method based on range size
- **Even Number Skipping**: Optimized trial division avoiding even divisors
- **Efficient Sieve**: Uses Sieve of Eratosthenes for large ranges
- **Memory Management**: Handles large calculations efficiently
- **Progress Indicators**: Real-time feedback for long operations

## Output Features

- **Formatted Display**: Large numbers with comma separators
- **Statistics Dashboard**: Count, timing, and rate information
- **File Export**: Save prime lists to text files
- **Visual Enhancement**: Emojis and clear formatting
- **Interactive Controls**: Ctrl+C handling and user-friendly menus

## Mathematical Insights

Includes educational content about prime properties, distribution patterns, famous conjectures, and practical applications in cryptography and computer science.

## Requirements

- Python 3.6+
- Standard libraries: math, sys, time, os
- Cross-platform compatibility

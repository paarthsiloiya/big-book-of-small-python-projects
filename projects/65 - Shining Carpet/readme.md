# Shining Carpet

Recreate the iconic and mesmerizing carpet pattern from the movie *The Shining* right in your terminal! This program generates a tessellated hexagonal design using simple ASCII characters.

## How to Run

1.  Run the script using Python.
2.  Enter the desired **width** (how many times the pattern repeats horizontally).
3.  Enter the desired **height** (how many times the pattern repeats vertically).

## Example Output

If you enter a width of `2` and a height of `1`, the output will look like this:

```text
_ \ \ \_/ ___ \ \ \_/ __
 \ \ \___/ _ \ \ \___/ _
\ \ \_____/ \ \ \_____/ 
/ / / ___ \_/ / / ___ \_
_/ / / _ \___/ / / _ \__
__/ / / \_____/ / / \___
```

## Features

-   **Customizable Size**: You control how big the carpet is.
-   **Instant Art**: Generates a complex-looking pattern instantly.
-   **Simple Code**: Easy to understand and modify.

Enjoy the hypnotic pattern!

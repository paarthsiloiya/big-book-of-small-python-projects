# Tower of Hanoi

A classic mathematical puzzle where you must move a stack of disks from one rod to another.

## How to Play

1.  The game consists of three rods (A, B, and C) and a number of disks of different sizes.
2.  The objective is to move the entire stack from rod **A** to rod **C**.
3.  Only one disk can be moved at a time.
4.  Each move consists of taking the upper disk from one of the stacks and placing it on top of another stack.
5.  No disk may be placed on top of a smaller disk.

## Input

-   Enter the source tower followed by the destination tower (e.g., `AB` to move from A to B).
-   Type `QUIT` to exit the game.

## Running the Game

Run the script using Python:
```bash
python main.py
```
